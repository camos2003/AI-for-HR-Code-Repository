# Hours Tracker

A single-file, offline HTML tool for logging freelance/consulting hours and turning them into bi-weekly approval summaries and printable invoices. No install, no server, no accounts — open the file in any browser and everything saves locally in that browser (`localStorage`).

## What it does

- **Log time in plain language** — type or paste entries like `.5 hrs 7/19`, `40 mins 730 - 810`, `4:30-5 on 7/20`, `plus one hour`, or an `Hrs: .5 7/20` shorthand. Paste a whole email thread and it pulls the dates from the headers.
- **Daily / weekly / monthly / all-time totals** — automatic, no math.
- **Bi-weekly summary** — assembles a ready-to-send approval email (per-week, per-day breakdown) you can copy or open in your mail client.
- **Invoice** — turns a period's hours into a clean, printable invoice (Print / Save PDF), with editable business, client, rate, and remit details.
- **Import / export** — CSV and JSON export, JSON backup/restore, and merge-import with duplicate protection.

## Privacy

All data lives only in your browser's local storage. Nothing is uploaded anywhere. This published copy ships with **placeholder** business, contact, and bank details — set your own in the tool's settings; your real values are saved locally and never leave your machine.

## Usage

Open `Hours_Tracker.html` in any modern browser. That's it. To keep it, bookmark the file or add it to your home screen.
